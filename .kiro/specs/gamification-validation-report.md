## 3. 発見された問題点・改善提案

### 3.1 🔴 重大な問題: ユーザーレベルと習慣レベルの比較ロジックが未実装

**現状:**
- レベルダウン候補の検出は「完了率 < 50%」のみで判定
- ユーザーレベルと習慣レベルの差分は考慮されていない

**設計ドキュメントの記載:**
> 「ユーザーLvに対し習慣Lvがあまりにも高すぎる場合、AICoachingでベビーステップの提案をしてくれるようになっているか」

**問題:**
- 初心者ユーザー（User Lv.10）が上級者向け習慣（Habit Lv.150）を追加しても、完了率が50%以上であれば警告されない
- ユーザーの成長段階に合わない習慣を継続させてしまう可能性

**改善提案:**
```typescript
// 追加すべきロジック
const levelGap = habit.level - userLevel.overallLevel;
const LEVEL_GAP_THRESHOLD = 50; // ユーザーレベルより50以上高い習慣は警告

if (levelGap > LEVEL_GAP_THRESHOLD) {
  // ベビーステップ提案をトリガー
  suggestBabySteps(habit.id);
}
```

### 3.2 🟡 中程度の問題: 習慣作成時のレベル適合性チェックがない

**現状:**
- 習慣作成時にTHLI-24評価はオプション
- ユーザーレベルとの適合性チェックなし

**改善提案:**
- 習慣作成時に推定レベルを表示
- ユーザーレベルとの差が大きい場合に警告メッセージを表示
- 「この習慣はあなたの現在のレベルより高めです。ベビーステップから始めますか？」

### 3.3 🟡 中程度の問題: Workload設定とレベルの整合性検証がない

**現状:**
- `workload_per_count`, `workload_total`, `frequency` は手動設定
- THLI-24レベルとの整合性チェックなし

**問題:**
- ユーザーが「毎日30分ジョギング」と設定しても、THLI-24評価では「週3回15分」相当のレベルになる可能性
- 主観的な設定と客観的な評価の乖離

**改善提案:**
- THLI-24評価後にWorkload設定を自動調整するオプション
- 設定値と評価値の乖離が大きい場合に警告

### 3.4 🟢 軽微な問題: 主観評価の反映が不十分

**現状:**
- THLI-24は24変数で客観的に評価
- ユーザーの「難しいと感じる」主観は直接反映されない

**改善提案:**
- 習慣完了時に「今日の難易度はどうでしたか？」の簡易フィードバック
- 主観評価が継続的に高い場合、レベル再評価を提案

## 4. レベル計算の妥当性検証

### 4.1 習慣レベル (THLI-24) の妥当性

**検証ケース: 「毎日30分ジョギング」**

| 変数 | 想定スコア | 根拠 |
|------|-----------|------|
| ⑱ 頻度 | 8.3 | 毎日 |
| ⑬ 所要時間 | 5.5 | 30分 |
| ⑦ 身体的努力 | 5.5 | 中程度の有酸素運動 |
| ⑩ 移動距離 | 2.8 | 近所を走る |
| ⑪ 準備/片付け | 2.8 | 着替え、シャワー |
| その他 | ~10 | 低〜中程度 |

**推定レベル: 約75-85 (intermediate〜advanced)**

この推定は妥当と考えられる。毎日30分のジョギングは中級者向けの習慣。

### 4.2 ユーザーレベルの妥当性

**検証ケース: 3つの習慣を持つユーザー**

| 指標 | 値 | 計算根拠 |
|------|-----|---------|
| 習慣継続力 | 60 | ストリーク7日、完了率70%、アクティブ率100% |
| レジリエンス | 70 | 回復率80%、バウンスバック2回、回復率100% |
| 専門性平均 | 40 | 3ドメインで各Lv.40 |

**総合レベル計算:**
```
(40 * 0.5) + (60 * 0.25) + (70 * 0.25) = 20 + 15 + 17.5 = 52.5 → Lv.52 (intermediate)
```

この計算は妥当。3つの習慣を70%の完了率で継続しているユーザーは中級者相当。

## 5. 推奨アクション

### 優先度: 高
1. **ユーザーレベルと習慣レベルの比較ロジックを実装**
   - `LevelManagerService` に `detectLevelMismatch()` メソッドを追加
   - 習慣レベルがユーザーレベル+50以上の場合にベビーステップ提案

### 優先度: 中
2. **習慣作成時のレベル適合性チェックを追加**
   - AIコーチの `create_habit_suggestion` ツールにレベルチェックを追加
   - 警告メッセージとベビーステップオプションを表示

3. **Workload設定とTHLI-24レベルの整合性検証を追加**
   - 評価後にWorkload自動調整オプション
   - 乖離警告の実装

### 優先度: 低
4. **主観評価フィードバック機能の追加**
   - 習慣完了時の簡易難易度フィードバック
   - 継続的な高難易度フィードバック時の再評価提案

---

## 6. 結論

ゲーミフィケーション機能の基本的な実装は完了しており、各レベル計算式は設計ドキュメント通りに実装されています。

ただし、**ユーザーレベルと習慣レベルの比較に基づくベビーステップ提案**という重要な機能が未実装です。現在のレベルダウン検出は完了率のみに基づいており、ユーザーの成長段階と習慣の難易度の不一致を検出できません。

この機能を追加することで、ユーザーが自分のレベルに合った習慣を維持し、無理なく成長できるシステムになります。
