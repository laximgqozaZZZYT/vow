# AI Coach Guardrails - Requirements

## Overview
AI Coachの動作を制御するガードレールとspecの定義。
ユーザーとの会話において、適切な範囲内で深堀りを行い、習慣管理に特化したコーチングを提供する。

## User Stories

### 1. 役割の明確化
**As a** ユーザー
**I want** AIコーチが習慣管理に特化した応答をする
**So that** 関係のない話題に脱線せず、効果的なコーチングを受けられる

#### Acceptance Criteria
- [ ] 1.1 習慣管理に関係のない質問には「習慣管理に関することでお手伝いできます」と応答する
- [ ] 1.2 医療・法律・金融アドバイスは行わない
- [ ] 1.3 政治・宗教に関する意見は表明しない

### 2. 深堀り機能
**As a** ユーザー
**I want** AIコーチが曖昧な入力に対して確認質問をする
**So that** より適切な習慣を作成できる

#### Acceptance Criteria
- [ ] 2.1 「運動する」のような曖昧な入力に対して、具体的な運動の種類を確認する
- [ ] 2.2 頻度が指定されていない場合、頻度を確認する
- [ ] 2.3 時間帯が指定されていない場合、時間帯を確認する
- [ ] 2.4 ユーザーが「それで進めて」と言った場合は確認せずに進める

### 3. UIコンポーネントの活用
**As a** ユーザー
**I want** AIコーチが習慣提案時に専用のUIコンポーネントを使用する
**So that** 提案された習慣を簡単に編集・作成できる

#### Acceptance Criteria
- [ ] 3.1 習慣提案時は構造化されたフォーマットで出力する
- [ ] 3.2 提案には名前、タイプ、頻度、目標、理由を含める
- [ ] 3.3 フロントエンドのHabitFormコンポーネントと連携する

### 4. ガードレール
**As a** システム管理者
**I want** AIコーチが危険な習慣を提案しない
**So that** ユーザーの安全を確保できる

#### Acceptance Criteria
- [ ] 4.1 過度な断食や極端な運動は提案しない
- [ ] 4.2 依存性のある行動を習慣として推奨しない
- [ ] 4.3 他者に害を与える可能性のある習慣は提案しない

## Technical Notes

### 実装ファイル
- `backend/src/services/aiCoachSpec.ts` - Spec定義とガードレール関数
- `backend/src/services/aiCoachService.ts` - AIコーチサービス本体

### スコープ外判定パターン
```typescript
const outOfScopePatterns = [
  /天気/, /ニュース/, /株価/, /政治/, /宗教/,
  /恋愛相談/, /占い/, /ゲーム.*攻略/, /レシピ/,
  /翻訳して/, /プログラム.*書いて/
];
```

### 深堀りが必要なパターン
- 運動系: 具体的な運動の種類が不明
- 学習系: 学習対象が不明
- 頻度: 毎日/週X回などの指定がない
- 時間: 時間帯や所要時間の指定がない
