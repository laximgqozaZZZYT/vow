## 概要

### MOCセクションとは

MOC（Multi-agent Orchestration Center）セクションは、VOWアプリケーションのAIエージェントハブとして機能します。ユーザーは複数のAIエージェントとチャットし、習慣（Habit）、目標（Goal）、メモ/タスク（Sticky'n）の提案を受けたり、既存の登録情報を見直したりできます。

**主な機能:**
- AIエージェントとの対話型チャット
- 構造化された質問フローによる提案
- Habit/Goal/Sticky'nの候補表示と採用
- 提案の詳細度調整（具体化・一般化・難易度）

### チャット機能の目的

MOCチャット機能は、以下の目的で設計されています：

1. **パーソナライズされた提案**: ユーザーの既存データを分析し、最適な習慣・目標を提案
2. **構造化された会話**: 段階的な質問フローで、ユーザーのニーズを明確化
3. **即座の行動**: 提案された候補をワンクリックで編集画面に移行
4. **柔軟な調整**: 提案の詳細度や難易度をリアルタイムで調整可能

## 候補ボタンの種類

MOCチャットでは、4種類の候補ボタンが表示されます。それぞれ異なる目的と動作を持ちます。

### 1. Habit型 (📝 青)

**用途**: 習慣の提案

**表示内容:**
- アイコン: 📝
- バッジ色: 青 (Blue)
- バッジテキスト: "Habit"

**クリック動作:**
- Habit編集モーダル（HabitModal）を開く
- 提案内容が事前入力された状態で表示

**表示例:**
```
┌─────────────────────────────────────────────────┐
│ 📝 毎朝10分の瞑想                    [Habit]   │
│ 朝起きたら、静かな場所で10分間の瞑想を行います。│
│ 頻度: 毎日 | 所要時間: 10分                      │
│                                                 │
│ [✅ 採用]  [❌ 却下]            [詳細を確認 →] │
└─────────────────────────────────────────────────┘
```

### 2. Goal型 (🎯 紫)

**用途**: 目標の提案

**表示内容:**
- アイコン: 🎯
- バッジ色: 紫 (Purple)
- バッジテキスト: "Goal"

**クリック動作:**
- Goal編集モーダル（GoalModal）を開く
- 提案内容が事前入力された状態で表示

**表示例:**
```
┌─────────────────────────────────────────────────┐
│ 🎯 3ヶ月で5kg減量                     [Goal]   │
│ 健康的な食事と運動で、3ヶ月以内に5kg減量します。│
│ 期限: 2026-05-05 | 親Goal: 健康管理            │
│                                                 │
│ [✅ 採用]  [❌ 却下]            [詳細を確認 →] │
└─────────────────────────────────────────────────┘
```

### 3. Sticky'n型 (📌 黄)

**用途**: メモ/タスクの提案

**表示内容:**
- アイコン: 📌
- バッジ色: 黄 (Yellow)
- バッジテキスト: "Sticky'n"

**クリック動作:**
- Sticky'n編集モーダル（StickyModal）を開く
- 提案内容が事前入力された状態で表示

**表示例:**
```
┌─────────────────────────────────────────────────┐
│ 📌 ジムの入会手続き               [Sticky'n]   │
│ 近所のジムに入会申し込みをする。                │
│ 関連Goal: 健康管理 | 関連Habit: 週3回の運動    │
│                                                 │
│ [✅ 採用]  [❌ 却下]            [詳細を確認 →] │
└─────────────────────────────────────────────────┘
```

### 4. 回答型 (💬 ティール)

**用途**: クイック返信・選択肢

**表示内容:**
- アイコン: 💬 (または選択肢に応じたアイコン)
- バッジ色: ティール (Teal)
- バッジテキスト: "Reply"

**クリック動作:**
- ボタンのラベルテキストがユーザーメッセージとして送信される
- AIエージェントが返信し、会話が続く

**表示例:**
```
┌───────────────────┐ ┌───────────────────┐
│ 📋 既存Habitの    │ │ 🎯 既存Goalの     │
│    見直し [Reply] │ │    新Habit提案    │
└───────────────────┘ └───────────────────┘
```

## アクションボタン

Habit/Goal/Sticky'n型の候補カードには、3種類のアクションボタンが表示されます。

### [採用] ボタン

**機能**: 提案を採用し、編集画面を開く

**動作:**
1. 対応するモーダル（HabitModal/GoalModal/StickyModal）を開く
2. 提案内容が各フィールドに事前入力される
3. ユーザーが必要に応じて編集・保存できる

**使用シーン:**
- 提案内容がそのまま使えそうな場合
- 提案をベースに少し調整したい場合

### [却下] ボタン

**機能**: 提案を却下し、非表示にする

**動作:**
1. 該当の候補カードが非表示になる
2. 次回のAI提案では、この内容を除外する

**使用シーン:**
- 提案が自分に合わない場合
- 別の提案を見たい場合

### [詳細] インジケーター

**機能**: 編集画面を開いて詳細を確認

**動作:**
- [採用]ボタンと同じ動作
- 矢印アイコン (→) で示される

**使用シーン:**
- 提案の詳細を確認してから採用を決めたい場合
- 各フィールドの内容を見たい場合

## 会話フロー

MOCチャットは、構造化された質問フローに基づいて動作します。ユーザーのニーズを段階的に明確化し、最適な提案を生成します。

### Step 1: 情報種類の選択

会話の最初に、ユーザーが欲しい情報の種類を確認します。

**選択肢 (6種類):**

| 選択肢 | 説明 | 次のアクション |
|--------|------|----------------|
| 📋 既存Habitの見直し | 登録済みの習慣を分析し、改善提案を行う | ユーザーのHabit一覧を表示 |
| 🎯 既存Goalに関する新しいHabitの提案 | 登録済みの目標に関連する習慣を提案 | ユーザーのGoal一覧を表示 |
| ✨ 新しいGoalの提案 | 新しい目標を提案 | Step 2へ（カテゴリ選択） |
| 📝 新しいHabitの提案 | 新しい習慣を提案 | Step 2へ（カテゴリ選択） |
| 📊 既存の登録情報の確認 | 現在の習慣・目標の統計を表示 | サマリー表示 |
| 💬 その他アドバイス | 自由形式の質問・相談 | フリーフォーム会話 |

**表示例:**
```
🤖 AI Coach
どのようなサポートが必要ですか？

┌──────────────────┐ ┌──────────────────┐
│ 📋 既存Habitの   │ │ 🎯 既存Goalの    │
│    見直し        │ │    新Habit提案   │
└──────────────────┘ └──────────────────┘
┌──────────────────┐ ┌──────────────────┐
│ ✨ 新しいGoalの  │ │ 📝 新しいHabitの │
│    提案          │ │    提案          │
└──────────────────┘ └──────────────────┘
┌──────────────────┐ ┌──────────────────┐
│ 📊 登録情報の    │ │ 💬 その他        │
│    確認          │ │    アドバイス    │
└──────────────────┘ └──────────────────┘
```

### Step 2: カテゴリの選択

新しいHabit/Goalの提案を選んだ場合、興味のあるカテゴリを選択します。

**カテゴリ (8種類):**

| カテゴリ | アイコン | 説明 |
|----------|----------|------|
| 健康 (Health) | 🏃 | 食事、運動、睡眠など |
| キャリア (Career) | 💼 | 仕事、スキルアップ、転職など |
| 学習 (Learning) | 📚 | 勉強、資格取得、語学など |
| 趣味 (Hobby) | 🎨 | 趣味、クリエイティブ活動など |
| 人間関係 (Relationships) | 👥 | 家族、友人、パートナーなど |
| 財務 (Finance) | 💰 | 貯金、投資、節約など |
| ライフスタイル (Lifestyle) | 🏡 | 生活習慣、整理整頓など |
| その他 (Other) | 📌 | 上記以外 |

**表示例:**
```
🤖 AI Coach
どのカテゴリに興味がありますか？

┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐
│🏃健康 │ │💼キャリ│ │📚学習 │ │🎨趣味 │
└───────┘ └───────┘ └───────┘ └───────┘
┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐
│👥人間関│ │💰財務 │ │🏡ライフ│ │📌その他│
└───────┘ └───────┘ └───────┘ └───────┘
```

### Step 3: サブカテゴリの選択

カテゴリを選択すると、より具体的なサブカテゴリを選択できます。

**サブカテゴリの例 (健康カテゴリ):**

| サブカテゴリ | 説明 |
|--------------|------|
| 運動・フィットネス | ジョギング、筋トレ、ヨガなど |
| 食事・栄養 | バランス食、カロリー管理、レシピなど |
| 睡眠 | 睡眠時間、睡眠の質改善など |
| メンタルヘルス | 瞑想、ストレス管理、マインドフルネスなど |
| 健康診断・予防 | 定期検診、予防接種、健康管理など |

**表示例:**
```
🤖 AI Coach
健康のどの分野に焦点を当てますか？

┌─────────────────┐ ┌─────────────────┐
│ 運動・フィットネス│ │ 食事・栄養       │
└─────────────────┘ └─────────────────┘
┌─────────────────┐ ┌─────────────────┐
│ 睡眠             │ │ メンタルヘルス   │
└─────────────────┘ └─────────────────┘
```

### Step 4: AI提案の生成

Step 1～3の選択内容に基づき、AIが適切な提案を生成します。

**提案内容に含まれる情報:**
- 名前（Habit/Goal/Sticky'n名）
- 説明
- 頻度（daily/weekly/monthly）
- 所要時間・負荷
- 推奨理由
- 関連する目標や習慣

**提案数:**
- 通常3～5個の候補を表示
- 詳細度調整ボタンで追加提案を要求可能

**表示例:**
```
🤖 AI Coach
健康 > 運動・フィットネス の提案です：

┌─────────────────────────────────────────────────┐
│ 📝 毎朝10分のストレッチ              [Habit]   │
│ 起床後、全身のストレッチを10分間行います。      │
│ 頻度: 毎日 | 所要時間: 10分                      │
│ [✅ 採用]  [❌ 却下]            [詳細を確認 →] │
└─────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────┐
│ 📝 週3回のジョギング                 [Habit]   │
│ 火・木・土の朝、30分間のジョギングをします。    │
│ 頻度: 週3回 | 所要時間: 30分                    │
│ [✅ 採用]  [❌ 却下]            [詳細を確認 →] │
└─────────────────────────────────────────────────┘

[もっと具体的に] [もっと一般的に]
[もっとかんたんに] [もっとむずかしく]
```

## 詳細度調整

提案された候補の詳細度や難易度を調整するボタンが用意されています。

### [もっと具体的に] (More Specific)

**効果**: より具体的で実践しやすい提案を生成

**変更内容:**
- 具体的な行動内容を含める
- 時間、場所、頻度を明示する
- すぐに始められるステップを示す

**使用例:**
- Before: "運動の習慣をつける"
- After: "毎朝7時に近所の公園で20分間ジョギングする"

### [もっと一般的に] (More General)

**効果**: より幅広い適用可能性のある提案を生成

**変更内容:**
- 柔軟に調整できる内容にする
- 複数のアプローチを提示する
- 個人の状況に合わせやすくする

**使用例:**
- Before: "毎朝7時に近所の公園で20分間ジョギングする"
- After: "週に3回、好きな時間に30分程度の有酸素運動をする"

### [もっとかんたんに] (Easier)

**効果**: より簡単で始めやすい提案を生成

**変更内容:**
- 所要時間を短縮
- 頻度を減らす
- 難易度を下げる

**使用例:**
- Before: "週5回、30分間のジョギング"
- After: "週2回、10分間の散歩"

### [もっとむずかしく] (Harder)

**効果**: より高度で挑戦的な提案を生成

**変更内容:**
- 所要時間を増やす
- 頻度を上げる
- 難易度を上げる

**使用例:**
- Before: "週2回、10分間の散歩"
- After: "週5回、30分間のジョギング + 週3回の筋トレ"

### ボタンの配置

詳細度調整ボタンは、提案カードの下に表示されます。

```
┌─────────────────────────────────────────────────┐
│ [提案カード1]                                   │
│ [提案カード2]                                   │
│ [提案カード3]                                   │
└─────────────────────────────────────────────────┘
┌─────────────────┐ ┌─────────────────┐
│ 🔍 もっと具体的に│ │ 🌐 もっと一般的に│
└─────────────────┘ └─────────────────┘
┌─────────────────┐ ┌─────────────────┐
│ 😊 もっと簡単に │ │ 💪 もっと難しく │
└─────────────────┘ └─────────────────┘
```

## 使用例

### 例1: 新しいHabitの提案を受ける

1. MOCセクションを開く
2. AIエージェントとのチャットを開始
3. "📝 新しいHabitの提案"をクリック
4. "🏃 健康"カテゴリをクリック
5. "運動・フィットネス"サブカテゴリをクリック
6. AIが3つのHabit候補を提案
7. 気に入った候補の[採用]をクリック
8. HabitModal が開き、内容を確認・調整
9. [保存]で習慣を登録

### 例2: 既存Habitの見直し

1. MOCセクションを開く
2. "📋 既存Habitの見直し"をクリック
3. AIが現在のHabit一覧を分析
4. 改善提案が候補として表示される
5. 提案を採用するか、[もっと具体的に]で詳細化
6. 気に入った提案を[採用]してHabitを更新

### 例3: 提案の詳細度を調整

1. 初回の提案が「毎朝7時にジョギング」だった場合
2. [もっと一般的に]をクリック
3. AIが「週3回、好きな時間に有酸素運動」という提案を生成
4. さらに[もっとかんたんに]をクリック
5. AIが「週2回、10分間の散歩」という提案を生成
6. 自分に合ったレベルの提案を[採用]

## まとめ

MOCチャット機能は、構造化された会話フローとインテリジェントな提案により、ユーザーが効果的に習慣・目標を管理できるようサポートします。

**主要な利点:**
- 段階的な質問で、ユーザーのニーズを明確化
- パーソナライズされた提案
- ワンクリックでの採用・編集
- リアルタイムでの詳細度調整

**今後の拡張:**
- 音声入力対応
- クロスセッション会話記憶（バックエンド対応）
- ドラッグ&ドロップでの候補並び替え
